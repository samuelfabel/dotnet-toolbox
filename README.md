# dotnet-toolbox

A collection of focused .NET utilities, experiments, and implementation examples.

The repository is organized by area. Each project is self-contained and may include its own source code, dependencies, usage example, and documentation.

## Repository layout

Projects are grouped by their main area of responsibility. See the README in each project directory for its purpose, requirements, and usage instructions.

## Working with the projects

Use the project-specific instructions to build and run an individual component. Requirements and commands may differ between projects.

## Contributing

Keep additions focused and place each component in the directory that best matches its responsibility. Include project-level documentation when an example needs setup instructions, usage details, or technical context.
